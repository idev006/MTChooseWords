# อัลกอริทึมจัดวางคำแบบ Grid-constrained Packing

## เป้าหมาย

จัดวางคำจำนวนมากบนกระดาษ A4 โดยไม่ทับ Title ไม่ซ้อนกันเอง และยังรักษาความสุ่มแบบทำซ้ำได้ด้วย Seed

## ขั้นตอนหลัก

1. คำนวณ `safe_area` หลังหัก page margin, title และระยะห่างจาก title
2. แบ่ง safe area เป็น Grid ขนาดประมาณ `3 px = 2.25 pt` เนื่องจาก PDF ใช้หน่วย point
3. เรียงคำจากกรอบที่คาดว่าจะใหญ่ไปเล็ก
4. สร้างกรอบสี่เหลี่ยมจากความกว้างฟอนต์ ความสูงฟอนต์ padding และองศาหมุน
5. ใช้ Grid เป็น spatial index เพื่อค้นหาตำแหน่งที่มีโอกาสว่าง
6. ตรวจ Bounding Box จริงซ้ำก่อนยืนยันตำแหน่ง
7. จอง cell และกรอบของคำที่วางแล้ว
8. ถ้าหน้าแน่นตั้งแต่ 80 คำขึ้นไป จะลอง compact mode ก่อน โดยใช้ขนาดฟอนต์ต่ำสุดและองศา 0 องศา เพื่อควบคุมเวลา
9. หากยังไม่สำเร็จ จะลดขนาดฟอนต์และช่วงองศาทีละรอบ โดยไม่ต่ำกว่าค่าที่ผู้ใช้กำหนด

## โครงสร้างโค้ด

- `core/geometry.py` รับผิดชอบกรอบหลังหมุน การตรวจชน และการแปลงกรอบเป็น cell
- `core/grid_packer.py` รับผิดชอบ Grid index, candidate points และ adaptive packing
- `core/pdf_generator.py` รับผิดชอบการวาด PDF และแปลงผลลัพธ์เป็น Placement

## เหตุผลด้านประสิทธิภาพ

Grid ไม่ได้ใช้ตรวจทุกกรอบกับทุกกรอบ แต่เก็บ mapping จาก cell ไปยัง index ของกรอบที่เกี่ยวข้อง จึงตรวจ geometry เฉพาะคำใกล้เคียง ลดเวลาจากการตรวจแบบ O(n²) ในทางปฏิบัติ

## กรณีวางไม่ได้

ถ้าจำนวนคำและข้อจำกัดฟอนต์ไม่สามารถวางได้จริง ระบบจะแจ้งให้ลดจำนวนคำต่อหน้า ลดฟอนต์ขั้นต่ำ ใช้แนวนอน หรือปรับพื้นที่ Title/margin โดยไม่ลดฟอนต์ต่ำกว่าค่าที่ผู้ใช้ตั้งไว้
