# Product Requirements Document (PRD)

## 1. วิสัยทัศน์

MT Choose Words เป็นแอปพลิเคชันข้ามระบบปฏิบัติการสำหรับสร้าง PDF แบบฝึกคำศัพท์ โดยจัดวางคำแบบสุ่มอย่างมีศิลปะ สีสันสวยงาม และไม่ให้คำซ้อนกัน

## 2. ผู้ใช้งานเป้าหมาย

- ครูและผู้จัดทำแบบฝึกภาษาไทย
- ผู้ปกครองที่ต้องการสร้างสื่อการเรียนรู้
- ผู้ใช้ที่ต้องการสร้าง word cloud แบบควบคุมจำนวนคำและรูปแบบ

## 3. Functional Requirements

| ID | ความต้องการ | เกณฑ์ยอมรับ |
|---|---|---|
| FR-01 | นำเข้าคำจาก source ที่ตรวจรับได้ | Production import อ่านเฉพาะไฟล์ `.docx` หรือ `.txt` ที่ตรวจรับได้ และเก็บคำที่ไม่ซ้ำใน SQLite |
| FR-01A | Reload คลังคำ | ล้างข้อมูลเดิมก่อน import ใหม่แบบ atomic transaction และแจ้งจำนวนคำที่โหลดได้ |
| FR-01B | เลือกระดับชั้นคำศัพท์ | ผู้ใช้เลือก ป.1-ป.6 ได้หลายระดับชั้นด้วย checkbox และระบบสุ่มคำจากระดับชั้นที่เลือกเท่านั้น |
| FR-01C | สกัดคำจาก Word DOCX | อ่านเฉพาะ cell คำศัพท์ในตารางของไฟล์ `.docx` จาก `app/assets/words/lot1` โดยไม่อ่านหัวเรื่องหรือข้อความนอกตาราง |
| FR-01D | รองรับ source adapter แบบปลอดภัย | Reload production ใช้ `.docx` และ `.txt` เท่านั้น ส่วน PDF อยู่ใน diagnostic-only จนกว่าจะมีกระบวนการตรวจรับที่เชื่อถือได้ |
| FR-01D2 | สกัดคำจาก Text file | อ่าน UTF-8 `.txt` แบบหนึ่งคำต่อหนึ่งบรรทัด โดยระดับชั้นมาจากชื่อไฟล์ เช่น `คลังคำศัพท์ภาษาไทย_ป1_VISUAL_VERIFIED.txt` |
| FR-01E | ตรวจรับ content import | ระบบต้องหยุด import เมื่อ source ไม่ผ่าน contract และสร้างรายงาน evidence หลัง reload สำเร็จ |
| FR-01F | เลือกไฟล์ source | ผู้ใช้เลือกไฟล์ `.docx`/`.txt` ที่ต้องการ import ได้หลายไฟล์ หรือใช้ทั้งโฟลเดอร์ที่ตั้งค่าไว้ |
| FR-01F2 | Import journal | ทุกครั้งที่อ่าน source ต้องสร้าง `mtchoosewords_import_journal.json` ในโฟลเดอร์ source เพื่อบันทึกผลอ่านและเหตุผลที่บล็อก |
| FR-01G | Import mode | ผู้ใช้เลือกได้ว่าจะล้างคำทั้งฐานข้อมูลก่อน import หรือ append เข้าไปโดยไม่ล้างของเดิม |
| FR-02 | กำหนดจำนวนหน้า | ผู้ใช้กำหนดจำนวนหน้าด้วยตัวเลขอารบิก |
| FR-03 | กำหนดจำนวนคำต่อหน้า | ระบบแจ้งเตือนเมื่อจำนวนคำไม่เพียงพอ |
| FR-04 | ปรับขนาดฟอนท์ | รับค่า minimum/maximum และลดขนาดภายในช่วงที่กำหนด |
| FR-05 | หมุนคำ | รองรับองศาต่ำสุด/สูงสุดตามที่ผู้ใช้กำหนด |
| FR-06 | เลือกฟอนท์ | แสดงฟอนท์ `.ttf`, `.otf`, `.ttc` จากโฟลเดอร์ฟอนท์ |
| FR-07 | สีคำ | สุ่มจาก color palette ใน TOML |
| FR-08 | ป้องกันการซ้อน | คำต้องไม่ชนกันและต้องไม่ทับพื้นที่ Title |
| FR-09 | Title | กำหนดข้อความ สี ขนาด และระยะห่างด้านบนได้ โดยจัดกึ่งกลาง |
| FR-10 | ขนาดกระดาษ | สร้าง PDF A4 แนวตั้งและแนวนอน |
| FR-11 | บันทึกการตั้งค่า | บันทึกค่าล่าสุดลง `config.toml` |
| FR-12 | Progress/Status | แสดงความคืบหน้าและข้อผิดพลาดที่เข้าใจได้ |

## 4. Non-functional Requirements

- Python 3.12 ใน `.venv` ของโครงการเท่านั้น
- UI ภาษาไทย
- ไม่พึ่งพา OS locale สำหรับการแสดงตัวเลข
- รองรับ Windows, macOS และ Linux
- การสร้าง PDF ต้องทำงานเบื้องหลัง ไม่ทำให้ UI ค้าง
- โครงสร้างต้องรองรับ pytest และ PyInstaller โดยไม่ต้องแก้ source code หลัก
- ข้อมูลคำใช้ SQLite ผ่าน SQLAlchemy ORM และใช้ `grade + normalized word` เป็น primary key

## 5. ขอบเขตนอก MVP

- Production import จาก PDF/OCR หลังมีกระบวนการตรวจรับ 100%
- Preview PDF แบบ interactive
- การกำหนด layout theme ขั้นสูง
- การแพ็กเป็น installer ของทั้งสามระบบปฏิบัติการ
